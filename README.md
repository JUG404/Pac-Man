# PacMan Mouth Animation (Java Swing)



### Description

This project is a simple Java Swing program that imitates the PacMan character by creating an animated mouth movement. The mouth opens and closes continuously using a timer, giving the effect of the classic PacMan animation.



### Features

\- Created using Java Swing and AWT graphics.

\- Draws a yellow PacMan shape using the `fillArc()` method.

\- Animates the opening and closing of PacMan's mouth.

\- Uses a `Timer` to update the animation smoothly.

\- Simple graphical user interface with a title label.



### Technologies Used

\- Java

\- Java Swing

\- Java AWT

### How It Works

The program creates a custom JPanel where PacMan is drawn using the `Graphics` class. The mouth movement is controlled by changing the starting angle and arc size values. A Swing Timer updates these values every 100 milliseconds, creating the animation effect.



### How to Run

1\. Make sure Java is installed on your computer.

2\. Download or clone this repository.

3\. Compile the Java file: javac JDemoFill.java

4\. Run the program: java JDemoFill
